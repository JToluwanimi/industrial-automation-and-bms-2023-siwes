# Fire Alarm Systems

## Types

### Conventional Fire Alarm
- Zones connected to a single circuit
- Control panel identifies zone, not exact device
- Cost-effective for small buildings

### Addressable Fire Alarm
- Each device has unique address
- Control panel identifies exact location
- Better for large/complex buildings
- Gent panel observed

## Components

- **Control Panel** — System brain (Gent observed)
- **Initiating Devices** — Smoke, heat, flame, manual call points
- **Notification Appliances** — Horns, strobes, sirens, speakers
- **Power Supply** — Battery backup
- **Wiring** — Fire-rated cables

## Loop Configuration

Addressable systems use **loop wiring** (not star):

- Devices connected in a continuous loop
- Control panel communicates with each unique address
- Fault-tolerant — loop continues even if one device fails

## Installation Process

1. **Planning** — Layout, device placement, code compliance
2. **Preparation** — Gather equipment, coordinate with contractors
3. **Mounting** — Detectors, call points, panel
4. **Wiring** — Fire-rated cables, loop topology
5. **Addressing** — Assign unique device addresses
6. **Programming** — Configure zones, sensitivity, notifications
7. **Commissioning** — Test each device, verify communication
