# Field Installation Notes

## Site Preparation

Before any installation:
1. Site survey to identify camera positions, access points
2. Verify existing infrastructure (power, network)
3. Coordinate with client and other contractors
4. Prepare equipment staging area

## Camera Mounting (Outdoor)

- **Tools:** Ladder, drill, masonry bits, cable ties, weatherproof junction boxes
- **Safety:** Two-person team, harness for high work
- **Process:**
  1. Mark mounting position (pencil)
  2. Drill anchor holes
  3. Mount bracket
  4. Attach camera
  5. Route Cat6 cable through conduit
  6. Terminate RJ45 connector
  7. Test with PoE injector before final mounting

## NVR Rack Deployment

- **Rack:** 42U server cabinet
- **Order (top to bottom):**
  1. Patch panel
  2. PoE switch
  3. NVR (16 bays)
  4. UPS
  5. Cable management tray
- **Cabling:** Labelled Cat6, managed with velcro ties

## Field Safety

- **Electrical:** Lock-out/tag-out procedures for 220V AC work
- **Height:** Fall protection for rooftop and ladder work
- **PPE:** Safety boots, hi-vis vest, gloves
- **Communication:** Two-way radio for multi-team coordination
