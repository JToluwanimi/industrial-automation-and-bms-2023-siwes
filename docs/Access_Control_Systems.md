# Access Control Systems

## Types Studied

### 1. Full Height Turnstile Revolving Door
- Robust 304 stainless steel
- 5-million-cycle lifespan
- Hydraulic damper
- Fail-safe / Fail-lock modes

### 2. Radar Turnstile Swing Barrier Gate
- Touchless radar detection
- Adjustable sensing range
- Bi-directional operation
- Integrates with card/biometric/facial recognition

### 3. Tripod Turnstile
- 3-arm design
- Single entry point
- Mechanical or electronic operation
- Anti-tailgating

### 4. Full Height Automatic Flap Gate Turnstile
- Full-height barriers
- Automatic operation
- Directional control

### 5. 90° Biometric Full Height Turnstile
- Fingerprint/facial recognition
- RS485 communication up to 1,200 m
- UPS provisioning

## Access Control Architecture

```
Card/Biometric/PIN -> Controller -> Electric Lock -> Entry
                    |
                    v
            Software (User DB, Logs, Reports)
```

## Standalone vs. Centralized

| Feature | Standalone | Centralized |
|---------|-----------|-------------|
| Control | Local per door | Central controller |
| Cost | Lower | Higher |
| Scalability | Limited | High |
| Reporting | Basic | Comprehensive |
| Integration | Limited | Full (CCTV, fire) |
